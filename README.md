# Ninho — landing page

Página de vendas do Ninho (HTML/CSS/JS puro, sem build), recriada a partir do
artifact de referência. Contém: seção hero com calculadora de fase do bebê,
seção "uma noite qualquer", demonstração em abas, canção de ninar, histórias,
preços e FAQ.

## Rodar localmente

Abra `index.html` direto no navegador, ou sirva a pasta com qualquer servidor
estático (ex.: `npx serve .`).

## Deploy

Hospedado na Vercel como site estático (sem etapa de build).
